# Web Development Practice Repository

## Description
This repository documents my journey in learning web development. It contains exercises and projects that combine HTML, CSS, and JavaScript to build simple web pages and applications. The goal is to gradually enhance my skills by completing small tasks and practicing fundamental concepts.

## Structure
The repository has the following folders:

- **exercises/**: Contains individual exercises focusing on specific topics in HTML, CSS, and JavaScript.
- **practices/**: Includes hands-on practice files that show web development techniques.
  - **html/**: Practice files related to HTML tags and structures.
  - **css/**: Exercises focusing on CSS styling and layout techniques.
  - **javascript/**: JavaScript practice files covering syntax, functions, and DOM manipulation.
  - **combined/**: Projects that combine HTML, CSS, and JavaScript to create interactive web pages.
- **projects/**: Future projects showcasing more complex web applications.
- **resources/**: A collection of learning resources, tutorials, and references.
- **templates/**: Basic templates for HTML, CSS, and JavaScript that you can reuse for new projects.
