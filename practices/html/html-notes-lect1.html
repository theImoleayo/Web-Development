The HTML Element

An HTML element is the fundamental unit of an HTML document, representing a specific part of a webpage. It consists of:

  1. Opening Tag: The start of the element.
  2. Content: The text, media, or content formatted by the browser.
  3. Closing Tag: The end of the element.
Example:

<h1>This is the first heading of an HTML</h1>

  • Opening Tag: <h1>
  • Content: This is the first heading of an HTML
  • Closing Tag: </h1>

Self-Closing and Empty Elements

Some elements are self-closing, meaning they do not require a closing tag. Additionally, empty elements are those that do not hold content.

Examples of empty elements:

<br> <!-- Line Break -->

<img src="image.jpg" alt="A beautiful image"> <!-- Image -->

<hr> <!-- Horizontal Rule -->

Key Components of an HTML Element

  1. Tag Name: The name of the HTML element, e.g., <p>, <img>, <div>.
  2. Opening Tag: Marks the beginning of the element, e.g., <p>.
  3. Closing Tag: Marks the end of the element, e.g., </p>.
  4. Attributes: Optional properties that provide additional information, e.g., src for an image.
  5. Content: The text, images, or other elements that appear within the tag.

HTML Element Attributes

HTML attributes modify the behavior or appearance of elements and are added within the opening tag as name-value pairs.

Example of an image element with attributes:

<img src="image.jpg" alt="A beautiful image">

  • src: Specifies the source URL for the image.
  • alt: Provides alternate text for the image.

Common HTML Attributes

  1. id: Assigns a unique identifier to an element.
  2. class: Assigns one or more class names for grouping and styling.
  3. style: Specifies inline CSS styles.
  4. href: Defines the target URL for hyperlinks.
  5. target: Specifies where to open a linked document.
  6. title: Provides a tooltip text when hovering over an element.
  7. width: Defines the width of an element (like images or videos).
  8. height: Defines the height of an element.

Summary

HTML Elements consist of opening and closing tags, or are self-closing.

  • Tag: e.g., <p> A new paragraph </p>
  • Opening Tag: e.g., <div>, <h1>, <section>
  • Closing Tag: e.g., </div>, </h1>, </section>
  • Self-Closing Tags: e.g., <input>, <img>, <br>
  • Empty Elements: e.g., <br>, <hr>

Attributes: Provide additional information or control the behavior of HTML elements, such as making content accessible, adding unique identifiers, or applying styles.
